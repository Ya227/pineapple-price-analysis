# Анализ цен ананасов в Москве (2021–2025)
Проект посвящён анализу выборочных цен ананасов в Москве за период с 04.06.2021 по 14.03.2025.
Работа выполнена на Python с использованием библиотек NumPy, Pandas, Matplotlib, SciPy и включает расчёт статистических метрик, визуализацию данных и анализ распределения.

## Цели проекта
* исследовать выборочные цены ананасов;
* рассчитать основные статистические показатели;
* выявить выбросы;
* построить гистограммы, boxplot, вариационный ряд и эмпирическую функцию распределения;
* сравнить распределение с нормальным законом.

## Основные результаты
* Объём выборки: **196**
* Среднее арифметическое: **273.62**
* Медиана: **273.36**
* Стандартное отклонение: **62.46**
* Межквартильный диапазон: **79.83**
* Обнаружено **4 выброса**
* Распределение близко к симметричному (медиана ≈ среднему)
* Нормальное распределение не описывает данные — гистограмма шире и имеет выбросы

## Использованные методы
* описательная статистика;
* квартильный анализ;
* анализ выбросов (IQR);
* вариационный ряд;
* частотная и вероятностная гистограммы;
* сравнение с нормальным распределением;
* эмпирическая функция распределения (ECDF).

## Технологии
